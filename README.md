A tiny program that writes exactly one sentence to `/output/entry.txt` —
the best advice I ever got, handed over with a towel by a line cook after
I dropped a full tray: **"Clean it up before you explain it."** The line
was drafted with an OpenCode free-model round, then won a criteria-ordered
tournament against the judge's published criteria (one sentence of advice
actually received, worth carrying, a real voice in a real moment, tight
in one breath, and landing with something to keep), beating "Send it
before you love it" and the nurse's question. Output is byte-exact:
144 UTF-8 bytes, no trailing newline. Run it with `python3 main.py`.
